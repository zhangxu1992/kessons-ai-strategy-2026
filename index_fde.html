FDE · Forward Deployed Engineer

🔬 什么是 FDE？

FDE（Forward Deployed Engineer，前线部署工程师） 是 AI/数据公司的关键岗位，本质是"把技术产品送进客户现场并真正跑起来的人"。最典型的推动者是 Palantir Technologies — 他们不靠标准化 SaaS 取胜，而是派遣工程师驻扎客户现场，深入业务、理解痛点、定制方案、持续迭代。

💡 在模型层高度同质化的今天（GPT-4o、Claude 3.7、DeepSeek V4-Pro benchmark 差距极小），谁能帮客户真正把 AI 用起来，谁就赢得合同续约和扩张。企业 AI 预算已从"探索期"进入"交付期"，CFO 开始追问 ROI — 这正是 FDE 的历史性窗口。

科森斯定位：对每一个签约客户，创始人作为"客户的 FDE"，做到三件事 — 走进现场（了解业务流程）、搭建 Agent（基于真实场景）、陪跑到会（培训+跟踪直到客户独立使用）。这不是做项目，是做客户的"AI 合伙人"。

SWOT 战略分析

💪 优势 (Strengths)

  • 50+ 存量客户直达决策层，FDE 模式天然需要"进现场"
  • 创始人兼具销售+FDE 交付能力，可独立完成全链条
  • 深耕财税/律所/印刷/汽修/工厂五大垂直行业
  • EasyClaw 作为交付载体，行业 Agent 模板可实现 80% 复用
  • 极低固定成本，AI Native 自运营模式

⚠️ 劣势 (Weaknesses)

  • 产能极度受限：1 人无法同时进行 FDE 交付、销售、Agent 开发
  • 品牌认知为"软件定制公司"，新定位需要建立
  • 缺乏标准化 Agent 模板库和培训课件
  • 无专家/讲师合作资源，行业培训依赖外部

🚀 机会 (Opportunities)

  • 东莞市政府 2026"人工智能+"城市方案：1000 亿产业规模
  • 开源大模型万亿参数时代，AI 成本断崖下降
  • 企业 AI 培训市场 320 亿（2026），70% 落地难
  • FDE 模式欧美已验证（Palantir），国内尚属空白
  • 星流科技等推动 Agent Native Server，降低部署门槛

🔥 威胁 (Threats)

  • 金管道 AI、三鼎科技等本地竞品具备品牌势能
  • AI 大厂（阿里千问、字节豆包）推出低价/免费 Agent
  • 客户可能认为直接用大模型即可，不需要付费 FDE
  • AI 技术迭代极快，Agent 工具链可能快速演进

💰 财务维度

  • ARR ≥ 100 万

👥 客户维度

  • NPS ≥ 8 分
  • 客户数 20

  • 客户均 3 个 Agent

  • FDE 交付 80h → 40h
